# MikroTik Tools for GLPI 1.0.1

This maintenance release confirms compatibility with GLPI 12.x. The plugin was upgraded and tested on GLPI 12.0.2 in the Connect IT test environment; the user verified its device actions and workflows. GLPI 11.x support from version 1.0.0 is retained.

## Compatibility

- Declared GLPI compatibility: `^11.0 || ^12.0`.
- Tested GLPI versions: 11.0.9 (previous release) and 12.0.2 (this release).
- PHP requirement remains 8.2 or later, according to the GLPI version in use.
- No router configuration changes are required for the GLPI 12 update.

## Validation

- The user tested the plugin on the upgraded GLPI 12.0.2 test server and confirmed its functions worked.
- Plugin prerequisite metadata allows GLPI versions from 11.0 through 12.x and excludes GLPI 13.
