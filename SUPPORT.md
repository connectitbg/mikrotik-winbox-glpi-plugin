# Support

This plugin is maintained by [Connect IT](https://connectit.bg).

Winbox - GLPI 0.4.6 is a free beta. There is no subscription, paid license, or formal support service. Connect IT monitors the public issue tracker and may address reproducible defects or improvements on a best-effort basis. The beta has been exercised on GLPI 11.0.9; compatibility with other versions and security review are ongoing. No paid stable release is currently offered.

Report a defect with the [Bug report form](https://github.com/connectitbg/mikrotik-winbox-glpi-plugin/issues/new?template=bug_report.yml).

Never attach passwords, router configuration exports/backups, one-time launch codes, or customer data to an issue.
